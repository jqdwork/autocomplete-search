
# Autocomplete Search

Autocomplete search built with MUI Autocomplete component, fetching users from the JSONPlaceholder API and displaying their address on selection.

## Getting Started
1. Clone the repository
```bash
git clone https://github.com/jqdwork/Autocomplete-search.git
cd Autocomplete-search
```

2. Install dependencies
```bash
npm install
```

3. Start the development server
```bash
npm run dev
```
